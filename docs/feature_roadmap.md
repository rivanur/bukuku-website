# Roadmap & Spesifikasi Fitur "Bukuku"

Dokumen ini adalah cetak biru untuk transformasi Bukuku dari proyek sederhana menjadi platform katalog buku yang serius dan profesional.

## 🚀 Fase 1: Fundamen & Modernisasi (Sedang Berjalan)

Fokus pada penguatan sistem inti dan migrasi ke teknologi yang skalabel.
- [ ] **Migrasi Database**: Pindah dari LocalStorage ke MySQL.
- [ ] **Backend Node.js**: Membangun API yang aman dengan JWT.
- [ ] **Pembersihan UI**: Desain minimalis tanpa icon emoji, Glassmorphism, dan CSS Variables.
- [ ] **User Authentication**: Sistem login/register asli dengan enkripsi password.

## ✨ Fase 2: Pengayaan Fitur Pembaca

Meningkatkan interaksi pengguna agar mereka betah di website.
- [ ] **Buku Favorit (Bookmarks)**: Pengguna bisa menyimpan buku yang mereka sukai ke dalam daftar pribadi.
- [ ] **Sistem Rating & Ulasan**: Memberikan bintang (1-5) dan komentar pada setiap buku.
- [ ] **Rekomendasi Buku**: Menampilkan buku-buku serupa berdasarkan kategori yang sedang dilihat.
- [ ] **Pencarian Lanjut (Advanced Search)**: Filter berdasarkan tahun rilis, rentang harga, dan rating.

## 🛠️ Fase 3: Dashboard Admin Profesional

Memberikan kendali penuh bagi pengelola konten.
- [ ] **Upload Sampul Gambar**: Integrasi Cloudinary atau S3 agar admin bisa mengunggah file foto sampul langsung.
- [ ] **Manajemen Kategori**: Menambah, mengubah, atau menghapus kategori buku langsung dari aplikasi.
- [ ] **Statistik Sederhana**: Grafik jumlah buku per kategori dan buku yang paling sering dilihat.
- [ ] **Log Aktivitas**: Mencatat siapa yang mengubah data buku dan kapan.

## 📱 Fase 4: Optimasi & Skalabilitas

Menjaga performa dan kehadiran di mesin pencari (SEO).
- [ ] **SEO & OpenGraph**: Meta tags yang lengkap agar saat website di-share di WA/Sosmed muncul gambar dan judul yang menarik.
- [ ] **PWA (Progressive Web App)**: Agar website bisa "di-install" di HP layaknya aplikasi native.
- [ ] **Caching**: Menggunakan Redis atau cache sederhana agar loading data sangat cepat.

## 💎 Fase 5: Ekspansi & Komunitas (Tingkat Lanjut)

Membawa Bukuku ke level platform profesional yang matang.
- [ ] **Sistem Langganan (Subscription)**: Fitur premium untuk akses buku-buku eksklusif.
- [ ] **Multi-bahasa (i18n)**: Dukungan bahasa Inggris agar bisa diakses pengguna global.
- [ ] **Diskusi & Komunitas**: Forum diskusi per buku atau grup baca bersama.
- [ ] **Integrasi Afiliasi**: Link ke marketplace (Shopee/Tokopedia) jika pembaca ingin membeli buku fisik.
- [ ] **Dark Mode / Light Mode**: Pemilihan tema website yang lebih nyaman untuk mata.
- [ ] **Automated Testing**: Menjamin website bebas bug dengan sistem testing otomatis di backend dan frontend.

> Kita akan fokus menyelesaikan **Fase 1** terlebih dahulu agar "pondir" (Pondasi) aplikasinya kuat sebelum masuk ke fitur-fitur canggih.
